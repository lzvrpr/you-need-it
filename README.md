# «Оно тебе надо»

Статическая вёрстка учебного проекта по макету аукциона.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не требуются.

## Структура

- `index.html` — семантическая разметка страницы.
- `styles/style.css` — единый файл: локальные шрифты, базовые правила и стили десктопного макета.
- `fonts/` — локальные файлы шрифта Raleway, подключённые из `style.css`.
- `images/` — изображения карточек, обложки, логотипы и иконки.

## Проверка по требованиям

- В документе есть `header`, `main` с тремя секциями и `footer`.
- Ссылки шапки ведут к секциям страницы; адрес размечен через `address`, `tel:` и `mailto:`.
- Для обложки и карточек используется общий принцип позиционирования полупрозрачного оверлея.
- Список лотов собран семантически из `ul`, `li`, ссылок и `article`; список переносится при нехватке ширины.
- Секция «Об аукционе» построена на двухколоночной сетке.
- В подвале есть навигационный список и ссылки на социальные сети.
- Пути к ресурсам относительные, страница открывается без LiveServer.
